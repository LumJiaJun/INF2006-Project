Serverless architecture

One flow, from raw data to useful decisions

Each managed service has a focused role, keeping the platform scalable and easier to operate.

01Source data

Raw listing CSV enters a private, versioned S3 data lake.

→
02Transform

AWS Glue cleans fields and writes city-partitioned Parquet.

→
03Understand

Athena serves controlled city summaries through Lambda.

→
04Predict

A container Lambda runs the trained scikit-learn pipeline.

→
05Remember

Cognito and DynamoDB protect each user's prediction history.

Secure by default

Private origins and least privilege.

S3 public access stays blocked, CloudFront uses origin access control, and each Lambda receives a narrow IAM policy.

Observable in production

Metrics that show what matters.

CloudWatch logs, alarms, and a shared operations dashboard track errors, throttles, traffic, and latency.

Responsible outputs

Useful estimates with clear limits.

Validation stays inside the model's known scope, city currencies remain explicit, and every result includes a disclaimer.
