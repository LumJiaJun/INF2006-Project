# Data

## Provenance

- **Dataset name:** Airbnb Listings and Reviews
- **Source:** https://www.kaggle.com/datasets/toufikbhm/airbnb-listings-and-reviews
- **Download status:** NOT YET DOWNLOADED. `data/sample/*.csv` are
  synthetic placeholders generated by `generate_dummy_data.py`, built
  to match the publicly documented column names and types.
- **Licence:** Not yet verified — check the Kaggle page's licence tab
  once downloaded, and record it in `DATA_DICTIONARY.md`.
- **Personal/sensitive data:** None. No real guest, host or payment
  data is used anywhere in this project. All bookings are simulated
  application data.

## Files

- `raw/` — where the real downloaded Kaggle CSV(s) should be placed
  (untouched, never edited in place)
- `sample/dummy_listings.csv`, `sample/dummy_reviews.csv` — synthetic
  data used for development until the real dataset is downloaded and
  inspected
- `processed/` — cleaned/transformed data produced by the pipeline
  (currently empty, populated by `analytics/train_price_model.py`)
- `DATA_DICTIONARY.md` — column-level documentation
- `generate_dummy_data.py` — regenerates the synthetic sample data

## Regenerating sample data

```
cd data
python3 generate_dummy_data.py
```

## When the real dataset arrives

1. Place the downloaded file(s) in `data/raw/`.
2. Run `python3 inspect_dataset.py data/raw/<file>.csv` — this prints
   and saves a factual report (row/column counts, dtypes, missing %,
   duplicates, numeric ranges, top categorical values) to
   `data/INSPECTION_REPORT.md`. Do this before assuming the file
   matches `DATA_DICTIONARY.md`.
3. Update `DATA_DICTIONARY.md` by hand using that report, noting any
   differences from the documented schema.
4. Point `analytics/train_price_model.py` and `src/backend/app/seed.py`
   at the real file instead of the dummy CSV (a single path argument).
